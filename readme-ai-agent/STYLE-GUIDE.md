# Style Guide & Design Tokens — Intellecta Clean Slate (Stitch)

## 1. Core Palette
- **Background**: `radial-gradient(circle at 10% 85%, rgba(215, 205, 245, 0.45) 0%, transparent 40%), radial-gradient(circle at 90% 15%, rgba(225, 230, 242, 0.6) 0%, transparent 50%), #DEDEE4`
- **Surface Cards**: `#FFFFFF` (Light) / `#18191F` (Dark) with `rounded-[32px]` (`rounded-4xl`).
- **Primary Charcoal**: `#18181B` / `#1C1D21` (Key buttons, titles, active rail pills).
- **Secondary Lime**: `#D2F27C` / `#D8F86E` (Milestones, success badges, active indicators).
- **Tertiary Lavender**: `#DCD4FB` / `#E0D5FC` (Break events, secondary categories).
- **Slate Accent**: `#D7DEEA` / `#CBD5E1` (Research cards, secondary chips).
- **Muted Text**: `#71717A` (Body labels, timestamp footers).

## 2. Typography Rules
- **Font**: Plus Jakarta Sans.
- **Headlines**: Bold/Extrabold (`text-3xl` to `text-5xl`), upright roman, tight tracking (`-0.03em`).
- **Metrics**: `tabular-nums` strictly enforced on all counts, percentages, and time values.
- **Buttons**: Pill-shaped (`rounded-full`), `active:scale-[0.98]`, min height `44px`.
